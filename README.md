## 📖 About This Course

This repository holds all assignments, labs, and quiz prep for **DATA 200** —
covering Python fundamentals through advanced data structures, algorithmic
complexity, and applied data analysis.

> **Instructor:** Paramdeep Saini · **Schedule:** Wednesdays, 6:00–8:45 PM · Room BBC 220

## 🧭 Topics Covered

| # | Topic | Key Concepts |
|---|-------|---------------|
| 1 | Python Basics | Built-in data structures I |
| 2 | Advanced Python | Lambdas, generators, dict/list/set/tuple, math identities |
| 3 | Object-Oriented Design | Classes, objects, constructors, `self`, composition |
| 4 | Linear Structures I | Stacks, queues, deque, priority queue |
| 5 | Linear Structures II | Linked lists & operations |
| 6 | Non-Linear Structures I | Binary trees (array & linked implementations), traversal |
| 7 | Advanced Topics | Maps, hash tables, skip lists |
| 8 | Non-Linear Structures II | Binary search trees, sorting & selection |
| 9 | Text Processing | Pattern matching, dynamic programming |
| 10 | Data Analysis I & II | Applied Python for analytics |
| 11 | Data Wrangling | Loading, cleaning, scaling, exploration |
